## 3. 缺陷清单

### D1 — BLOCKER — §3.1 表（格点保持条件）+ §3.1 流程（未规定算术类型）

**问题.** 计划规定用 `r̄+c̄ ∈ ℤ` 一类的判定来筛 8 个候选对称，但**没有规定用什么算术**。官方 example 的**绿色 3 格州质心是 (5/3, 8/3)**，在 IEEE754 双精度下：

```
rbar-cbar = -0.9999999999999998   ->  "∈ ℤ" 判定为 False
```

于是 `refD1` 被判为不保持格点 → 绿色州被判为"无对称" → **首都 (2,3) 丢失** → d 场少一个源 → **10 个官方数字全部对不上**。这是静默错误：不抛异常、不报"非法"，只是数字悄悄错了。

实测：同一套规则引擎，用 float 跑 → 绿州 `G=['id']`，status=`NO_SYMMETRY`；改用精确有理数 → 绿州 `G=['id','refD1']`，`|Fix(refD1)|=1`，capitol=(2,3)，10/10 全中。

**修正建议.**
1. 在 §3.1 明确：**规则内核禁止浮点**。对 n 格州，令 `sr=Σr, sc=Σc`，6 个整除条件全部写成整数取模：
   - `refD1`：`（sr−sc) % n == 0`，k1=(sr−sc)//n，映射 (r,c)→(c+k1, r−k1)
   - `refD2`：`(sr+sc) % n == 0`，k2=(sr+sc)//n，映射 (r,c)→(k2−c, k2−r)
   - `refH`：`(2*sr) % n == 0`；`refV`：`(2*sc) % n == 0`
   - `rot180`：两者皆整除；`rot90/270`：两者皆整除
   （这 6 条与计划表格里的 6 条条件**逐条等价**，我已用精确引擎对拍过；只是不许用 `/` 算质心。）
2. 加一条硬性验收：`rules.py` 不得 import/使用 `float` 除法（可加 lint 或代码评审清单）。
3. 回归测试里点名官方 example 的绿色 3 格州（质心 5/3, 8/3），断言它**仍有首都 (2,3)**。

### D2 — MAJOR — §3.5 Lemma L4

**问题.** L4 写成双向："`d(x) = 1 ⟺ x 紧邻一个单格州`"。**反方向是假的**。

反例（3×3，实测 d=0）：`A={(0,0),(1,2),(2,0)}`（镜像对称，首都 =(1,2)）、`B={(0,1),(0,2),(1,0),(1,1),(2,1)}`（十字，首都 =(1,1)）、`C={(2,2)}`（单格州，首都 =(2,2)）。
格 (1,2) 属于 A 且是 A 的首都 → d(1,2)=0；同时 (1,2) 与单格州 C 的 (2,2) 正交相邻 → "紧邻单格州"成立但 d≠1。

4000 次随机划分暴力搜索：**L4 反方向 1495 次违反**；正方向 0 次违反。

**修正建议.** 改为单向命题 + 明确边界：
- `d(x) = 1 ⟹ x 的某个邻格属于一个单格州`（**成立**，0 反例）
- `x 紧邻单格州 ⟹ d(x) = 1` **不成立**，除非 x 本身不是首都（即 d(x)≠0）
- 求解器里禁止写 `if adjacent_to_1cell(x): assert d[x]==1`；只能写 `d[x]==1 → 邻接有单格州`

### D5 — MAJOR — §3.1 "完备性论证"（结论对，论证缺一步）

**问题.** 计划写："任何保持 S 不变的等距变换必保持 S 的质心 μ。**故**候选变换只有 8 个。" 这是 non-sequitur：**固定一点的等距变换有无穷多个**（绕 μ 的任意角度旋转 + 过 μ 的任意直线反射）。质心论证只能把平移和滑移反射排除掉。

缺的正是计划 §7 Q1 问的那一步：**该等距变换还必须把单位方格格点集映到自身**。补上后：
- |S| ≥ 2 时，polyomino 边界同时含水平与竖直的单位边；等距变换把边界映到自身且保长，所以像格点集也必须同时含水平与竖直方向 ⇒ 旋转角必为 90° 的整数倍，镜像轴必为水平/竖直/对角线方向。
- |S| = 1 时，正方形的对称群恰为 D4（8 个），也正是这 8 个。
- 再由"固定 μ"钉死平移分量 ⇒ **候选恰好 8 个**。

**结论是对的**（我穷举验证：3×3 全部 218 个连通子集 + 4×4 全部 11,506 个连通子集，出现的对称群大小只有 **1 / 2 / 4 / 8**，从不出现 3 或 6——因为 120° 旋转保不住正方格点阵；也从未出现 45° 旋转或过格边中点的反射）。

**修正建议.** §3.1 补上这段论证（3–4 行），并把"保格点阵 ⇒ 只有 D4"作为 §3.1 的第一句。同时在 §3.1 流程第 3 步补一条：**若 |G| == 1（无非平凡对称），该形状不合法（S2 不成立），直接判非法，不要落进首都分支**——否则空集合上的 ∩ 会给出"全体格"这种无意义结果。

### D6 — MAJOR — §1.2 G2 / §3.3 第 5 步 / §3.4 第 3 步：唯一性定义在"划分"上，但交付物是"答案"

**问题.** G2 写"满足提示数字的合法划分**恰好 1 个**"。但求解器要交的是**答案**（Σ行和²），不是划分。实测 4×4：

- 合法划分 **561,468** 个
- 不同的 (d 场, 行和) 签名只有 **496,580** 个

**修正建议.**

- 保留"划分数"作为**诊断指标**输出（R3 已经要求求解器报解计数，方向是对的），但不要拿它当生成器的门。

### D8 — MAJOR — §3.3 第 3 步："d 场一致性剪枝"高估了自己的能力

**问题.** 计划写"局部分配一旦确定出某格的**所有邻格所属州的大小**，即可校验 |Δd| 约束"。但在**枚举器**里，d 场是未知的——你只知道**提示格**上的 d 值。所以能用的检查只有：
- 两个**都是提示格**的相邻格 x,y：`|D(x) − D(y)| ≤ min(s_x, s_y)`（L2），以及 `s_x ≥ |D(x) − D(y)|`（L3）；
- 单个提示格 x 的邻格 y 若**不是**提示格，d(y) 未知，**什么也校验不了**。

计划现在的措辞把"所有邻格的大小已知"当成充分条件，读起来像是 d 场全局已知——这会让人以为剪枝很强，从而低估枚举规模（与 D7 叠加）。

**修正建议.**
- §3.3 第 3 步改为显式分两种情形：*"只有当 x 与 y 都是提示格时，|Δd| 约束才可实例化；单侧已知时不可用。"*
- 补上真正能用的强剪枝（供实现参考）：
  - **前向可达性剪枝**：从"已确定有首都的州"出发做多源 Dijkstra 变体，得到"到最近已知首都的**下界** d_lb；若某提示格 x 的提示值 D(x) < d_lb(x)，则当前部分划分**不可能**成立 → 剪枝"。这是把 L1/L2 用在"部分已知"上，方向正确且便宜。
  - **上界剪枝**：若 d_lb(x) > D(x) 且任何未分配邻居的最小可能边权（≥1）都无法把差距补回来 → 剪枝。
- 在 §3.3 明确"5×5 的唯一性证明依赖这层剪枝，不是靠叶子暴力比对"。

### D9 — MAJOR — §3.4 策略 B（随机生长）产不出"划分"

**问题.** 策略 B 只描述了"长出一个形状"，**没有铺满/互斥/覆盖的步骤**；随机长出来的块可能互相重叠、可能留空洞，不构成"划分"。而生成器必须输出一个**划分**。

另外"每次扩张都镜像对称地**成对**加入"表述不准：加在镜像轴上的格（自镜像）只能加一个，加了它的镜像（已存在）才对称——正确规则是"加 x 的前提是 mirror(x) ∈ S ∪ {x}"。

还有"生成后统一跑 rules.py 校验（**S1-S3 + 至少一个首都**）"措辞歧义：官方 example 里**就有**一个无首都的 2×2 州，所以"至少一个首都"只能是**全图至少一个**，不能是"每州一个"。

**修正建议.**
- 策略 B 补全为两步：①镜像对生长产出形状（并写清"加 x 要求 mirror(x) ∈ S∪{x}"）；②**用随机化回溯把剩余格子铺满**（复用 §3.3 的回溯，顺序随机化），失败则重试。
- 或直接砍掉策略 B，把策略 A 写成**随机顺序的精确覆盖回溯**（先随机选下一个待覆盖格，再随机排序候选摆放）——这一条同时解决铺满、互斥、覆盖。
- 澄清"至少一个首都"=**整个划分至少有一个首都**；**允许个别州无首都**（与 §1.1 和官方 example 一致）。

### D10 — MINOR — §6 M6："27 个提示数字"

**问题.** 11×11 正式盘的提示数是 **33**，不是 27。像素验证：11 条横线（y=23…800，等距 70.5px）+ 12 条竖线（x=228…1005，等距 70.5px）→ 11×11 网格；逐格连通域统计，**33 个格子含墨**（每格 1–2 个数字字形），无杂散连通域。
逐行分布：4/1/3/4/3/3/3/4/3/1/4 = 33。

**修正建议.** M6 改成"**33** 个提示数字全部复现"，并交付一个人工核验过的黄金文件 `fixtures/official-11x11/numbers.json`（33 条），供 ocr.py 回归。

### D11 — MINOR — §3.2 前置校验措辞

"若一个州都没有首都 → 该划分非法" 会被读成"某个州没有首都就非法"，与官方 example（2×2 无首都）矛盾。改成："若**整个划分中一个首都都没有** → 非法（d 场无定义，无法给任何格赋 d）"。

### D12 — MINOR — §3.3 第 1 步自相矛盾

"（连通 + 有非平凡对称 + **S1-S3 成立**）" 紧跟着下一行"无首都的州**也是合法州**，必须一并纳入候选"。S3 不该出现在**合法性**筛选里。改成："S1 连通 + S2 有非平凡对称；**S3 只决定该州有没有首都，不影响它是不是合法州**"。

### D13 — MINOR — §3.6 "最小提示集"命名不成立

贪心"逐个删、删到不动点"得到的是**不可再删集（inclusion-minimal）**，不是**最小基数集**；结果依赖删除顺序。改名为"**不可再删提示集（irreducible）**"，并写清保证边界："再删任何一格都会破坏唯一性；**不保证**基数全局最小"。改进建议（进计划即可）：①用多个随机删除顺序各跑一遍取最小；②加一轮"成对删除"；③在 README 标注每个 fixture 的提示数与达到方式（因为"最难"是相对某个求解器/剪枝强度而言的）。

### D14 — MINOR — §3.7 / §5 R4："视觉通道"不可自动化

"像素通道 + 视觉通道交叉验证"里的"视觉通道"是人眼阅读，**无法写进自动化测试**（人眼不能作为 CI 断言）。改成：产出**一次人工核验**的黄金文件（`numbers.json`），自动化测试断言 `ocr(图片) == 黄金文件`；人眼交叉验证发生在**制作黄金文件时**，并把核验人和日期写进文件头注释。

### D15 — MINOR — §3.5 / 标题：从未把"度量"写成不变量

题目叫 "It's a Metric, Too"（既是度量也是测度），但计划通篇没把度量性质写成不变量，也没做测试。建议加：
- `w` 对称、严格正 ⇒ `dist` 是真度量（对称、三角不等式、`dist(x,x)=0`）；
- 明确区分 `dist(x,y)`（**度量**）与 `d(x)`（到最近首都的**势函数**，本身不是度量）——L2 的证明用的是 `dist` 的三角不等式，代码里别把两个东西混成一个变量。
- 加属性测试：对随机划分随机取两格，断言 `dist(x,y) == dist(y,x)`、`dist(x,z) ≤ dist(x,y)+dist(y,z)`。

### D16 — MINOR — §4.4 / §7 Q6：JSON 结构不够

除 D4 的字段修正外，建议 schema 增加：`state_symmetry[i]`（群元素名列表）、`state_fix_counts[i]`（各非平凡元素固定格数）、`state_capitol[i]`（格或 `null`）、`capitol_less_states`（无首都州列表）、`hint_cells`（提示格 → 值）、`d_field`。理由：调试时最费时间的就是"为什么这个州被判成无首都"，`|Fix|` 列表一眼可见。

### D17 — MINOR — §4 CLI：`solve` 吃不了官方图片

M6 要跑 11×11 图片，但 CLI 只有 `solve --grid <file.txt>`。加 `solve --image <png>`（走 ocr.py）+ `regress --official-11x11`，否则 M6 只能靠手工拼文本。

### D18 — MINOR — §3.4 / §3.6：生成器缺失败上限

"不唯一则换划分或换提示集" 是无界循环。加 `--max-attempts`（默认如 2000），超限就**如实报告"该种子生成失败"**并返回非零，不要死循环（沿用计划自己 R5 的纪律）。

### D19 — MINOR — §1.1 / §5 R2：11×11 的州边界**并未画在题面上**

像素证据：11×11 网格的 12 条横线 + 12 条竖线**全部是 1px 等宽黑线**（外框 2px），没有任何加粗的州边界；整个上部区域只有灰阶像素，**没有示例面板里的那种彩色填充**。官方原文也只说 "The 11-by-11 region above **can be subdivided** into various states"（"可以被划分"，不是"已被划分"）。

结论：**正式盘的州划分完全没给，必须由 33 个数字反推**。这直接放大 D6/D7 的风险（答案是否唯一取决于官方自己的意图，未必唯一）。计划 §1.1/§1.3 没有点明这一点，M6 的"输出答案 + 划分图"也隐含假设"能唯一还原划分"。建议在 §1.1 加一段显式说明，并把 M6 改成"输出**所有**候选答案及各自划分 + 明确标注是否唯一；若无解或非唯一，如实报告"。

## 4. §7 七个开放问题的逐条裁定

### Q1 对称候选集是否完备？→ **完备，但计划的论证缺一步**
- **裁定：8 个候选是完备的**，没有漏掉 45° 旋转、过格边中点的反射、或其他。
- 论证：保持 S 不变的等距变换必须（i）固定质心 μ（排除平移/滑移反射），（ii）把**单位方格格点阵**映到自身（|S|≥2 时边界同时含水平与竖直单位边 ⇒ 旋转角必为 90° 整数倍、镜像轴必为水平/竖直/对角线；|S|=1 时正方形对称群即 D4）。两条合起来 ⇒ 候选恰好 8 个。
- **实测佐证**：3×3 全部 218 个 + 4×4 全部 11,506 个连通子集，出现的对称群大小只有 **1/2/4/8**，**从未**出现 3、6 或其他——因为 120°/60° 旋转保不住正方格点阵。
- 计划要改：补上第 (ii) 步（见 D5）。**结论不用改，论证要补。**

### Q2 "无对称的连通块不是合法州"与原题一致吗？→ **一致，但应写成显式判据**
- 官方原文是**定义式**的："A 'state' is a connected group of 1 or more squares that is symmetric in some way" —— 即"对称"是"州"的**定义属性**，不是事后附加的条件。所以"完全无对称的块不是州"是原文的直接推论，**方向正确**。
- 原文那句"If every nontrivial ... leaves exactly 1 ..."对无对称形状"逻辑上空洞"的顾虑不成立：因为无对称形状**根本不是州**，不会进入该条件句。
- 官方给的两个例子（1×3 横条、X 五连块）都是**有对称但无首都**的形状，说明"对称但无首都"是合法州 —— 计划对此理解正确。
- **裁定**：保留 S2，并在 §3.1 流程里**显式写成判据**："判定合法州需 |G| ≥ 2；|G| == 1 的形状不是州（不是'无首都的州'，是'不是州'）"。这同时纠正 D3 里 L 四连块的归类。

### Q3 最小提示集贪心够用吗？→ **够用，但命名与保证要改**
- 贪心删到不动点给出的是**不可再删集**，不是**最小基数集**；保证是"再删任意一格都会破坏唯一性"。
- 够用（做基准集足够），但必须：①改名（见 D13）；②记录删除顺序/多次重启取最小；③在 README 里写明"最难"是相对于给定求解器与剪枝强度而言的，不是绝对难度。
- 成本提醒：每次删除判定 = 一次完整唯一性枚举；4×4 上唯一性枚举（记忆化 DP 计数）只要 0.2 s，可接受；但若用"枚举+逐叶算 d 场"的写法（实测 400 s/次），贪心就完全不现实。**所以 D7 的 DP 化改写是 §3.6 可用的前提。**

### Q4 引理 L2/L3 成立吗？→ **L2/L3/L1/L5 成立；L4 的双向命题是错的**
暴力搜索：4000 个随机划分（3×3 / 4×4 / 5×5），每次全量计算 d 场并逐条边检查。

| 引理 | 裁定 | 反例数 | 说明 |
|---|---|---|---|
| **L1**（d>0 ⇒ 存在邻格 d 恰降 w） | **成立** | 0 | 计划给的理由偏直觉。严格证法：取最近首都 c\* 与 x→c\* 的最优路径首步 v1，则 d(v1) ≤ dist(v1,c\*) = d(x) − w(x,v1)，同时三角不等式给 d(v1) ≥ d(x) − w(x,v1)，故**取等**。 |
| **L2**（\|d(x)−d(y)\| ≤ min(s_x,s_y)） | **成立** | 0 | 计划证明可再收紧：两种情形下 **w(x,y) 恒等于** min(s_x,s_y)（同州 w=���S\|=min；跨州 w=min(\|A\|,\|B\|)=min），而 \|d(x)−d(y)\| ≤ dist(x,y) ≤ w(x,y)。 |
| **L3**（s_x ≥ max_y\|d(x)−d(y)\|） | **成立** | 0 | L2 逐边取用，直接推论。 |
| **L4**（d(x)=1 ⟺ 紧邻单格州） | **反向为假** | **1495** | 见 D2。只保留"d=1 ⇒ 紧邻单格州"（0 反例）。 |
| **L5**（d(x)=0 ⟺ 首都格） | **成立** | 0 | 前提：全图至少一个首都（D11）。 |

另外：**§1.1 的"所有非平凡元素固定同一格"定理成立**（0 违反，范围同上两网全部连通子集）。但计划给的证明草稿（"两个反射之积是绕交点的旋转"）不完整——正确论证是：有限等距群固定一点 ⇒ 群是绕该点的循环群或二面体群；旋转只固定中心点，镜像轴必过中心；故若存在至少一个非平凡旋转（其唯一固定点 = 中心）且所有非平凡元素都只固定 1 格，则那个格必为中心；纯反射的情形（|G|=2）平凡成立。**结论对，论证要补。**

### Q5 4×4 枚举可行吗？→ **可行，且余量很大；计划估计准确**
- 实测：4×4 的连通子集 **11,506** 个，其中**合法州（连通 + 有非平凡对称）1,124** 个 ⇒ 计划"**千级**"的说法**准确**。
- 合法划分总数 **561,468**（枚举法与记忆化 DP 法两种独立方法一致）。
- **记忆化 DP 计数**（按"剩余格 mask"记忆）只访问 **1,984** 个不同 mask，纯 Python **0.2 s** ⇒ 计划"秒级完成"**成立**。
- 真正贵的是"枚举全部划分 + 每叶算一次 d 场"：实测 **400 s**（4×4）。所以 §3.3/§3.6 应改成**用 DP 计数做唯一性判定**（0.2 s），只在需要见证解时再跑单解搜索。
- **更省的做法（建议写进计划）**：
  1. 唯一性判定 → DP 计数（带提示剪枝），不枚举叶子；
  2. 需要"找出那一个解" → 在同一个 DP 上加"找到一个就停"的 DFS；
  3. 提示剪枝用 D8 的前向下界剪枝。
- 5×5 见 D7：合法摆放 22,041、合法划分 2.6×10⁹、DP 计数 239 s。**5×5 可以"计数"但不能"枚举+逐叶比对"。**

### Q6 ground_truth JSON 够用吗？→ **不够，而且示例本身是错的**
- 示例错误见 D4（`states` / `state_sizes` 两字段错，`grid`/`capitols`/`row_sums`/`answer` 对）。
- 缺字段见 D16：每州的对称群、|Fix| 列表、首都或 null、无首都州清单、提示格映射。
- 另需写死两条 schema 约定：`states[r][c]` 行优先；`state_sizes[k]` = 标签 k 的格数（**必须等于 states 里标签 k 的出现次数**，用一条 schema 校验器断言）。
- 建议加一条 `tests/fixtures/schema` 校验：所有 fixture 必须通过"标签计数 == state_sizes"与"Σ行和 == Σ|S|²"两条断言（这正是 D4 里被违反的两条）。

### Q7 官方 example 的 5×5 解唯一吗？→ **UNVERIFIED（未能在本次评审内穷举）**
- 我**没有**完成 5×5 全量"与 10 个提示相容的划分"计数，因此**不能**断言唯一或不唯一。
- 已知的规模事实：5×5 合法摆放 22,041、合法划分 2,638,025,192、DP 计数 239 s / 134,452 mask。按计划现在的"叶子算 d 场再比对"写法，2.6×10⁹ 次 d 场计算**不可行**。
- 官方原文从未声称 11×11 划分唯一，只要求交一个数（见 D19：11×11 根本没画州边界）。所以"唯一"这个概念本身要先定义清楚（答案唯一 vs 划分唯一，见 D6）。
- 建议计划把 Q7 变成一个**有预算的、可证伪的实验**：M2 里跑"5×5 提示引导搜索 + 计数 DP"，输出 `(解数, 是否穷尽, 节点数)`；无论结果如何都写进 README，不要先写"==1"再去找证据。
